What the colours mean
greendirection — above / up. Nothing else is ever green.
reddirection — below / down.
cyanhow much. Four brightnesses: unremarkable → notable → extreme. Same ramp for RVOL, float, market cap, short %, PM/ADR and sector heat. Bright means big, never good.
orangethe model's opinion — the score, and only the score.
violetsomeone else's opinion — another tool's shortlist, the CANSLIM list.
yellowyour own mark — the star you put there.
greyno claim — missing, below threshold, or switched off.
bluefurniture — links, borders, bar fills. Says nothing.

Screener scorecard
Which screeners find stocks that move. There is no stop, target or exit here — it measures how far each card ran after the entry time, in ATR. That is the only thing a screener is responsible for; whether a move is tradable is a question about setups, and comes after you know which screeners are worth keeping.

How Scoring Works
1. Accumulate R4A + R4B data for several trading days
2. Export CSVs from the Warehouse tab
3. Run processor.py to train the model
4. Start server.py — live scores appear on cards
