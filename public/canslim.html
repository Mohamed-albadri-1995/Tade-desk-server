how a name gets on and off this list
T8's Universe screener runs once a day (09:30–09:45 ET, weekdays) and writes whoever clears all six criteria. A name stays for 90 days from the last time it qualified, so this list changes with the earnings calendar and not with the market. Every tool tags its own cards from it — it is a label and never a filter, so nothing is excluded for being absent.

Held is how long a name has been on the list since it first qualified; months means it survived an earnings cycle. Expiring counts from the last confirmation, so a long-held name can still be about to drop off — and when it does, its badge turns off on every tool at once.
