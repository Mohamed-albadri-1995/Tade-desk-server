how this list is built
Anything shortlisted on any tool appears here, by design. Names picked by more than one tool sort to the top: independent agreement is a different proposition from one list's opinion.
getting these into TradingView
Every tool's picks in one list, exchange-qualified. Copy then paste into TradingView's watchlist symbol box, or Download and use Watchlist → ⋮ → Import list… — TradingView has no public way to write a watchlist from outside, so the import is the whole route in.

what qualifies, and for how long
Who is a growth company, decided once a day on earnings and sales rather than on what the tape did. A name stays for 90 days from the last time it qualified, so this changes with the earnings calendar and not with the market. Every tool tags its own cards from this list — it is a label and never a filter.
